Porchlight

your friendly neighborhood agent

A background agent that correlates neighborhood safety reports and wakes a human only when a real pattern emerges.
Strands Agents SDK · Amazon Bedrock · AWS “Agents for Humans” — Good Neighbor track

Three agents, three prompts

  • • Each agent gets one short system prompt and a narrow tool set — more reliable than one prompt governing classification, correlation and judgment at once.
  • • Sequential workflow, not handoffs: no loops to debug, one stage named in every error.
  • • Model matched to task — Haiku 4.5 for typed extraction, Sonnet 5 for tool selection, Opus 5 for the judgment call.
  • • Prompt caching on the shared system-prompt and tool-schema prefix.

Two independent signals

  • • Meaning — “guy hanging around the mailboxes” and “loitering near the parcel lockers” are one event described twice. Keyword matching finds neither from the other.
  • • Rate — two reports in a day is nothing on a busy block and alarming in a quiet cul-de-sac, so each zone is scored against its own history.
  • • Persistence runs as plain function calls, not agent tools — a model that skips embed_and_index would silently break the cluster and nothing would raise.

Built for real deployment

  • • Correlates on place and behavior, never on person descriptions — only redacted_text is embedded or stored.
  • • A cluster needs distinct reporters — four reports from one person is one anxious neighbor, not a pattern.
  • • A human approves before anything is sent — “it wakes a human” means a human decides.
  • • Raw text expires on a retention window; aggregate counts survive so baselines keep working.
